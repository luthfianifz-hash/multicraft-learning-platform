# MultiCraft

## Platform Pembelajaran dan Manajemen Proyek Multimedia

MultiCraft merupakan platform berbasis web yang dikembangkan untuk membantu
mahasiswa mempelajari dan mengelola proyek di bidang multimedia, khususnya
film, podcast, dan animasi.

Website ini merupakan hasil rebuild dan redesign dari repository latihan
pemrograman web dengan menyesuaikan tampilan, identitas, konten, serta
fitur sesuai dengan kebutuhan proyek.

## Fitur Website

- Dashboard dan halaman utama
- Materi pembelajaran multimedia
- Materi Film, Podcast, dan Animasi
- Informasi proyek multimedia
- Tombol interaktif untuk menuju bagian proyek
- Formulir kontak

## Materi Pembelajaran

### Film
Mempelajari dasar produksi film mulai dari ide, naskah, pengambilan gambar,
hingga proses produksi.

### Podcast
Mempelajari proses pembuatan podcast mulai dari menentukan topik, membuat
naskah, melakukan rekaman, hingga publikasi.

### Animasi
Mempelajari prinsip dasar animasi dan proses membuat gerakan karakter yang
menarik dan komunikatif.
